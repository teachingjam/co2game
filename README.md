# 생태계 탐정단 (Eco Detectives) - co2game

사라진 생물들의 비밀을 밝혀라! 기후위기와 이산화 탄소(CO₂) 증가로 인한 생태계 변화를 탐정 수사 형식으로 재미있게 학습하는 레트로 도트풍 웹 인터랙티브 게임입니다.

---

## 🎮 주요 기능 및 사건 목록

총 8개의 사건을 수사하며 기후 변화의 원인과 영향을 파헤칩니다.

1. **하얗게 변한 제주 바다**: 바다 수온 상승과 산성화, 산호 백화 현상 탐색
2. **강원도로 이사 간 사과밭**: 기온 상승에 따른 작물 재배지 북상 관찰
3. **꽃은 폈는데 벌이 없다**: 봄 개화 시기 변화와 생물 계절 엇박자
4. **굶주린 북극곰**: 북극 해빙 감소와 영구동토층 해빙 피드백
5. **잠기는 갯벌**: 1980년 vs 2050년 서해안 갯벌 해수면 상승 틀린그림찾기
6. **불타고 병드는 숲**: 가뭄, 산불 확산, 월동 해충 증가에 맞서 숲 지키기
7. **커졌는데 맛이 없다?**: CO₂ 농도 증가와 작물 생장 및 영양 불균형 판정
8. **최종 사건 (연결된 범인)**: 남극 먹이그물 붕괴와 최종 범인(이산화 탄소) 지목 및 기후 보고서 발급

---

## 🛠️ 기술 스택

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6)
- **Graphics & Assets**: Retro Pixel Art (Canvas 렌더링 & 고해상도 PNG 에셋)
- **Audio**: Web Audio API 기반 신디사이저 사운드 & BGM
- **Font**: Galmuri (갈무리 폰트 - OFL)

## 🚀 실행 방법

별도의 빌드 과정 없이 정적 웹 호스팅 또는 로컬 환경에서 바로 실행 가능합니다.

1. 저장소 클론:
   ```bash
   git clone https://github.com/teachingjam/co2game.git
   ```
2. `index.html` 파일을 웹 브라우저에서 직접 열거나 로컬 웹 서버(VS Code Live Server 등)로 실행합니다.
